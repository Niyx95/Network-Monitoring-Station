#Network Monitor Station

## Overview
ESP-32 based network monitor with LCD display
LED alerts, Grafana dashboard on Raspberry Pi5

## Hardware
- Raspberry Pi5
- ESP32-S (AI-Thinker)
- 16x2 I2C display
- Samsung 980 Pro m.2 SSD
- Waveshare PCIe bridge
